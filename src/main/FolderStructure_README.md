# GatherLink source layout

- `java/com/gather_link/`: Spring application, controllers, security, services, JPA entities and repositories.
- `resources/`: default local H2 and optional environment-driven MySQL configuration.
- `webapp/WEB-INF/jsp/`: server-rendered authenticated views.
- `../test/`: application-context and security/workflow integration tests.

The [root README](../../README.md) is the source of truth for setup, validation and supported product flows.
